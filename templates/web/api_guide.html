Every page in CineSync uses this API

The pages are built with HTML and JavaScript; their data comes from these endpoints and every button calls one of them. Click a GET link to open Django REST Framework's browsable API. From Postman or curl, log in with Basic authentication.

Try it with curl

# list showtimes
curl -u alice:demo12345 http://127.0.0.1:8000/api/showtimes/

# book seat 5 (two-phase commit)
curl -u alice:demo12345 -X POST -H "Content-Type: application/json" \
     -d '{"seat": 5}' http://127.0.0.1:8000/api/book/
